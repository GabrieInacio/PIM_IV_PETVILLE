2. Conectar o TiDB Cloud

No TiDB Cloud, entre na instância Starter — MySQL Compatible e clique em Connect. Copie Host, Port, Username e Password para os campos abaixo. A senha aqui é a do TiDB, não a do MySQL do computador nem a senha da sua conta do site.

Certificado CA (somente se o TiDB exigir)

Normalmente o Windows valida certificados TLS usando a loja de certificados do sistema. Se necessário, baixe o certificado CA indicado pelo TiDB.

Conexão protegida por TLS com verificação do certificado e do host (VerifyFull). O programa tenta criar o banco petville e as tabelas automaticamente. A senha da nuvem fica protegida na pasta do seu usuário Windows e não entra no ZIP.

3. Comprovar o armazenamento

Após ativar a nuvem, abra a área do cliente, crie um cadastro de teste e um pet. Depois, abra o SQL Editor do TiDB Cloud, selecione o banco petville e confira as tabelas Clientes e Pets.

Atenção: os dados antigos do MySQL local não são transferidos automaticamente para a nuvem. Eles continuam preservados no computador e podem ser acessados pelo botão Usar MySQL local. Para apresentar o TiDB, cadastre um usuário novo.

O sistema web e a API continuam no seu computador (localhost:5041). O que estará na nuvem é o banco de dados.
